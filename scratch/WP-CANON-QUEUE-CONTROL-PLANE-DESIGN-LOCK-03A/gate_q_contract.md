# Gate-Q contract

Normative schema: `research/schemas/gate_q_approval.schema.json`. Gate Q is Karl-only, exact-content-and-target-only, append-only, single-use approval for one admission. It binds the complete lineage/artifact/data/denominator/budget/vocabulary bundle and exact proposed queue bytes/path. Every authority flag is false. Schema validity alone never grants authority; the later writer must verify content and cross-artifact semantics.
