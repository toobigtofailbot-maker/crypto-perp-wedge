CORS FINDING (drove the passthrough design)
-------------------------------------------
Measured against the real tools.agent_inbox_intake app over a socket:
  OPTIONS /api/agent/intake-draft  (Origin + Access-Control-Request-Method: POST)
    -> HTTP 405
  POST /api/agent/intake-draft  (Origin set)
    -> no Access-Control-* response headers
Conclusion: a direct cross-origin browser JSON POST is impossible. The service
may not be modified by this package, so the UI posts to a same-origin passthrough
(package section 10.2: "documented local path").
