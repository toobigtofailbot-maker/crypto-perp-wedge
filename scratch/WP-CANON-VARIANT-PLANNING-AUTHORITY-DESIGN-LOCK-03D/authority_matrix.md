# Authority matrix

| Artifact/gate | Grants | Explicitly does not grant |
|---|---|---|
| Gate C | One exact canonical Spec write | Planning, Gate Q, queue, execution |
| Canonical Spec | Immutable declarative truth | Downstream approval by existence alone |
| Planning approval | One exact bounded VM preparation | Spec mutation, Sweep, Gate Q, queue, run/result/candidate/runtime |
| Variant Manifest | Frozen population evidence | Queue or execution |
| Gate Q | One exact inert queue admission | Dispatch or execution |
| Queue admission | `admitted_non_dispatched` state | Dispatch, scheduler autonomy, execution |
| Later dispatch authority | Only its separately approved scope | Candidate or trading authority unless separately granted |
