## 5. Option A — REJECT

Option A is the do-nothing baseline.

The current state that surfaced Path B reassessment is an empty active pipeline
with ready infrastructure. Locking A would freeze the project in the state that
prompted reassessment.

Rejection does not authorize execution. It only rejects the hold/no-Path-B
route as the locked reassessment decision.

No gates or locked criteria are modified.

No execution authority is created.

## 6. Option B — LOCK as-written

Option B is the smallest viable re-prime route.

It stays inside locked taxonomy and locked timeframe_status discipline. It adds
no taxonomy labels and moves no timeframe boundary. It preserves
Tier 4/protected-path boundaries.

It preserves candidate registration, hypothesis pre-registration, backtest,
and artifact restrictions unless a later execution-authorization package
explicitly permits those actions.

It preserves D2-006, D2-007, REC-5, permanent human gates, WP-S2c-100 locked
criteria, and Path B execution non-authorization.

Downstream cost remains bounded relative to the rejected broader routes.

Option B is locked as-written as the Path B reassessment design surface.

Locking B is not Path B execution authorization.

## 7. Option C — DEFER

Option C is conceptually close to B but introduces an input-combination grammar
design surface.

Grammar clarity and locked taxonomy source confirmation are not required to
lock B.

Deferral preserves C for a future Main turn if B's evidence supports follow-on
input-combination work.

C does not block WP-S2c-123.

No taxonomy labels are added or reinterpreted.

No execution authority is created.

## 8. Option D — REJECT

Candidate-instance dimension expansion risks unbounded parameter search.

It risks implicit candidate ranking, conflicting with ranking/promotion
authority boundaries such as G-3 / DR-6 / HG-3 where repo-confirmed.

Evidence segmentation creates REC-5 floor pressure.

Its downstream discipline cost is too high for the current locking route.

REC-5 remains absolute.

No pooled cross-segment inference below the REC-5 floor is authorized.

No ranking/scoring/recommendation authority is created.

## 9. Option E — REJECT

Option E is too broad and drift-prone for the current phase.

It spans strategy family, timeframe, and evidence-type dimensions
simultaneously.

It carries high and variable downstream cost.

It has higher likelihood of triggering schema, validator, or query-layer design
packages.

Option B covers the narrow viable re-prime case without expanding surfaces
ahead of evidence.

No broad expansion authority is created.

No schema/validator/query-layer changes are authorized.

No locked taxonomy/timeframe-status changes are authorized.

## 10. Option F — DEFER

Option F is a meta-option combining a narrow first slice with optional broader
slices.

The phased framing risks implied automatic continuation.

Locking B alone is cleaner: broader follow-on requires a fresh Main/Karl
decision against fresh evidence.

Deferral preserves F if later evidence makes a phased route appropriate.

Later phases are not queued or pre-authorized.

No automatic continuation authority is created.
