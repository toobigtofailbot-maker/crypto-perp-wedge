# Work Package Execution Report

Use this report-back structure for Codex execution packages:

- A. Branch / base
- B. Repo-truth discovery
- C. Delivered changes
- D. Validation results
- E. Validation gates
- F. Forbidden-scope check
- G. PR / push status
- H. Open escalations
- I. Ready for review

Expect each section to be concrete and audit-friendly:

- identify the actual branch and base
- state what repo facts were verified before editing
- list created and modified files
- report exact validation run status or explicit non-run reasoning
- confirm protected paths remained untouched when required
